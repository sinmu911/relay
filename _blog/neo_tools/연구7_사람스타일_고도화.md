# 연구7 — 글을 더 사람답게: 지금 어디서 막혔나와 다음 단계 (2026-10-14)

사장님 10-14 "글 사람 스타일로 고도화". 이미 있는 것: 말투사전 v2(10-01 채택) · 리얼엔진 1.2 · 검문소 B1.
이 글은 **새 규칙을 쌓기 전에, 최근 완성본이 v2 기준에서 실제로 어디가 모자란지**를 리얼엔진 기록(.cache/리얼엔진.json)으로 본 결과와 그에 맞춘 다음 단계다.
지키는 선은 그대로: 경험·감정은 재료에 있을 때만, 사장님께 질문을 강요하지 않음, 발행된 글 내용·제목은 사장님 승인 후.

## 1. 잰 결과 (리얼엔진 1.2, 완성본 4편 + 리얼고침 2편)

| 글 | 걸림 | 모자란 것 |
|---|---|---|
| 두바이렌트카 완성본 | 0 | 숫자 36.8 /1000자(기준 20 이하) · 감정 0 |
| 두바이실제쓴돈 완성본 | 0 | 숫자 39.9 · 감정 0 |
| 그랜드모스크 완성본 | 0 | 숫자 40.5 · 감정 0 |
| 두바이실제쓴돈 **리얼고침** | **2** | 긴 문장 8%(10~25) · 같은 어미 연속 6% · 숫자 39.8 · 감정 0 |
| 그랜드모스크 **리얼고침** | **3** | 짧은 문장 26% · 들쭉날쭉 0.59 · 같은 어미 연속 9% · 숫자 40.1 · 감정 0 |

**읽은 것 세 가지**
1. **말투 장치(문장 길이·어미·연결어)는 이미 사람 범위.** 손으로 쓴 완성본은 걸림 0. 여기서 장치를 더 넣으면 오히려 틀이 보인다.
2. **모든 글이 같은 두 곳에서 모자람: 숫자가 사람 글의 2배, 감정·장면이 0.** 사람 냄새가 안 나는 진짜 이유. 숫자는 쓰는 쪽에서 고칠 수 있고, 감정·장면은 재료(사장님 기억·사진)가 있어야만 채울 수 있다.
3. **자동 고침(리얼고침)이 글을 더 나쁘게 만든다.** 원본 걸림 0 → 고친 뒤 2~3. 리얼고침 본은 발행 후보에서 빼는 게 맞다.

## 2. 다음 단계 (쓰는 쪽 — 사장님 손 안 감)

### 2-1. 숫자 예산: 본문 1000자당 20 이하
- 본문에는 **판단에 필요한 숫자 한 개**만. 나머지(거주자 요금·여행사 요금·요일별 시간 등)는 "▶" 줄·정보 카드·표로.
- 같은 숫자를 본문·카드·FAQ에 세 번 쓰지 않는다. 카드에 있으면 본문은 "아래 카드에 적어 뒀어요".
- 날짜는 "2026년 9월 17일자" → "9월 중순"처럼 판단에 필요한 만큼만(출처 줄에는 정확히).

**예시 (그랜드모스크 '지금 입장료는 얼마냐면요' — 같은 사실, 본문 요금·날짜 숫자 줄이기)**

지금:
> 근데 지금 공식 안내엔 요금이 있어요.
> 해외 방문객 10디르함, UAE 거주자 5디르함, 여행사를 거치면 8디르함이에요.
> 일단 5월에 무료로 들어간 사람 입장에선 좀 낯설어요.
> 2026년 9월 17일자 언론 보도에도 방문객 입장료 도입 소식이 나와요.
> 정확히 며칠부터 받기 시작했는지는 확인하지 못했어요.

바꾸면:
> 근데 지금은 돈을 받아요. 해외 방문객 10디르함.
> 5월에 그냥 들어갔던 사람 입장에선 좀 낯설어요.
> 언론엔 9월 중순에 도입 소식이 나왔는데, 며칠부터인지는 못 찾았어요.
>
> ▶ UAE 거주자 5디르함 · 여행사 거치면 8디르함 (공식 안내, 2026년 9월 17일 보도)

(본문 숫자는 2개, 나머지는 ▶ 줄로. 사실은 하나도 빠지지 않음.)

### 2-2. 리얼고침 본 쓰지 않기
- 리얼엔진 `--고침` 결과는 참고로만. 발행·본문 교체 후보는 사람이 쓴 완성본.
- 검문소가 `_리얼고침` 파일을 받으면 "참고: 원본보다 걸림이 많음"을 띄운다(검문소 다음 판에서).

### 2-3. 재료 안에서 장면 살리기
일정표에 있는 사실만으로도 "표"가 아니라 "그날"로 쓸 수 있다.
- 시간 순서: "에티하드 타워 다음, 마지막 목적지" — 이미 잘 함. 글마다 한 번은 넣는다.
- 챙긴 물건·한 행동: "스카프는 한국에서 미리 사 갔어요" 같은 **내가 한 일 한 줄**을 각 소제목에 하나.
- 못 한 것·모르는 것 솔직히: "출입증을 어떻게 받았는지는 기록이 없어요" — 사람 글의 신호. 유지.

## 3. 사장님만 채울 수 있는 것 (선택 · 강요 없음)

감정 0 은 규칙으로 못 고친다(지어내면 NEO 1번 위반). 대신 **넣기 쉽게** 만든다.

- **사장님 한 줄 칸(선택)**: 완성본 소제목 1~2곳에 `【사장님 한 줄】 (그 자리에서 처음 든 생각)` 칸을 둔다.
  채워지면 그대로 넣고, **비어 있으면 발행 때 그 줄을 자동으로 지운다**(지금 검문소는 빈칸을 '걸림'으로 막음 → 이 칸만 '선택'으로 바꿈).
- **넣는 길**: 텔레그램에 음성·문자로 "모스크: 생각보다 넓어서 한참 걸었음" 한 줄 → 블로그 담당이 맞춤법만 고쳐 칸에 넣음.
- **진짜 사진 1장**: 지금 글은 전부 AI 설명 그림. 휴대폰 사진 1장이 말투 열 줄보다 사람 글로 보인다(연구3 사람 글 사진 8.6장/1000자). 있으면 대표 그림 다음에.
