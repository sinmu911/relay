# relay

중계현황(설치형 화면)과 블로그 글쓰기 화면을 여는 **공개 정적 사이트**입니다.
GitHub Pages로 https://sinmu911.github.io/relay/ 에서 열립니다.

- `index.html` · `app.html` · `sw.js` · `manifest.json` · 아이콘 — 중계현황 설치 앱 껍데기(화면 본체와 자료는 Apps Script 쪽에 있고 이 저장소에는 없습니다)
- `blog/write.html` — 폰·PC 글쓰기 화면(글은 비공개 저장소 `relay-content`의 `_blog/posts`에 저장됩니다)

원고·사진·내부 운영 문서(`_blog/`, `playbooks/`, `.claude/`)는 비공개 저장소 **relay-content**에 있습니다.
이 저장소에는 사이트를 여는 데 필요한 파일만 둡니다.
